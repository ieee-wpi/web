# Live quiz music

Optional looping music for the host screen. The game works without these files, because sound effects are synthesized in the browser.

| file | used for | source URL | license |
|---|---|---|---|
| `lobby.mp3` | lobby and scoreboard | | |
| `question.mp3` | while a question is open | | |

Rules:
- **CC0 / public domain only.** Pixabay Music, the Freesound "Creative Commons 0" filter, and OpenGameArt CC0 are good sources.
- **Never use Kahoot's music.** It's copyrighted.
- Keep each file under about 1 MB (mono, 96 kbps, under 60 s) and make it loop cleanly.
- Fill in the table above for every file you add.
